MOBILE APPLICATION

손위생 모니터링 AI

손위생 수행 여부를 현장에서 간편하게 기록하고, 수집한 기록을 바로 분석해 결과로 확인하는 모바일 애플리케이션입니다.

주요 기능

간편한 현장 기록

관찰 상황에서 최소한의 조작으로 손위생 수행 여부를 빠르게 기록합니다.

자동 분석

기록된 데이터를 바탕으로 수행률을 자동으로 산출하여 한눈에 보여줍니다.

기기 내 저장

모든 데이터는 사용자의 기기 안에만 저장되며 외부로 전송되지 않습니다.

계정 불필요

회원가입이나 로그인 없이 설치 즉시 사용할 수 있습니다.

개인정보 보호

본 앱은 이용자의 개인정보를 일절 수집하지 않습니다. 회원가입 절차가 없고, 광고나 분석 도구를 사용하지 않으며, 앱에서 생성된 모든 데이터는 이용자의 기기 안에만 저장됩니다.
